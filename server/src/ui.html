🖥️ AegisVault Server Console (:4000) — Kontrol Dongle & Enroll Biometrik Wajah

Server bertugas mengelola Hardware Dongle & menyimpan referensi Biometrik Wajah. Untuk interaksi Login & fitur Vault user, buka Client Next.js di http://localhost:3000.

Memindai USB...

🔌 1. Kontrol Aktivasi Hardware USB Dongle (.aegis_key)

Aktifkan/nonaktifkan dongle di sini, lalu amati perubahan status real-time di halaman Login Client (:3000).

Memuat status USB...

💾 Tanamkan Kunci Dongle (.aegis_key) untuk User

📸 2. Rekam & Simpan Biometrik Wajah User di Server

Rekam foto wajah referensi ke database Server (dienkripsi AES-256-GCM) untuk dicocokkan saat user scan wajah di Client.

Nyalakan kamera Server atau pilih file foto wajah untuk mengekstrak 128-Float Vector.

👤 3. Data Akun, Dongle ID & Referensi Wajah Terdaftar di Database Server

Menampilkan status biometrik wajah dan kunci dongle yang sedang tersimpan di tabel SQLite User.
